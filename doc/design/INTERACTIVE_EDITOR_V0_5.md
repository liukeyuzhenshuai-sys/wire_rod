# Interactive Scene Editor V0.5 — 俯视拖拽版

## 目标

V0.5 将 V0.4 的“手工填写 X/Y/Z”改成业务人员可直接使用的场景摆放工具。

默认工作流：

1. 运行一个 Sequence 到最后一帧；
2. 点击“创建下一帧”；
3. 在车厢俯视图直接拖动已有盘条；
4. 选中盘条后用滑块修改 yaw、遮挡、滚动观测状态；
5. 点击“新增盘条”，再在车厢俯视图点击目标位置；
6. 可使用“吸附到最近邻”并设置目标 gap；
7. 右侧自动生成真实点云 3D 预览；
8. 点击“生成下一帧并运行识别”；
9. 若结果有问题，在主界面保存 failure ZIP。

## 交互规则

### 移动已有盘条

- 鼠标直接拖动盘条，修改 X/Y。
- Z 默认锁定，不在主界面要求用户填写。
- 选中后显示相对上一帧的 `ΔX / ΔY / ΔYaw`。
- 精确 X/Y/Z 仅保留在“高级参数”折叠区，用于回归复现。

### Yaw

- 主界面使用 yaw 滑块。
- yaw 是绕 Z 的轴方向变化，与滚动观测扰动独立。

### NEW

- 点击“+ 新增盘条”后进入放置模式。
- 在车厢俯视图点击即可确定 NEW 的 X/Y。
- NEW 首帧使用特殊红色。
- D/L/Layer/真实点云原型在选中 NEW 后设置。
- robot hint 偏差放在高级参数，不要求普通目检时填写。

### Gap

选中盘条后显示最近同层对象的近似 gap。可以设置目标 gap，并点“吸附到最近邻”。

该 gap 仅用于编辑器摆放辅助；正式算法输出仍使用 tracker 的 gap 计算逻辑。

### 遮挡

- 无 / 左侧 / 右侧 / 双侧；
- 强度滑块；
- 遮挡必须保留非零部分点云；
- 不允许把“零点”称为 OCCLUDED；零观测属于 UNOBSERVED。

### 业务异常场景

编辑器允许故意拖出顺序反转等不可能场景，但会显示红/黄 warning，不强制禁止生成。这用于对抗性测试。

## 3D 预览

编辑过程中 Web 调用：

`POST /api/session/{sid}/preview-next`

预览调用与最终 `create-next` 使用同一 `InteractiveSceneEditor` 点云生成逻辑，但不会提交 Session/Track 状态。

因此右侧看到的是实际生成器输出的抽样点云，不是简单的几何假图。

## 可复现性

最终点击“生成下一帧并运行识别”以后：

- PLY 仍写在工程根目录；
- failure ZIP 仍保存动作、随机 seed、GT、tracker state、算法结果、配置；
- 拖拽最终也会被转换为精确 `dx/dy/dz/dyaw` 写入 `edit_actions.json`。

所以拖拽提升交互体验，但不会降低问题案例的可复现性。
